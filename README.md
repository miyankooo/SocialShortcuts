# Social Shortcuts

A WoW Forever addon that lets you whisper, invite, ask to join or befriend a player by holding a modifier key and left-clicking their name. It skips the right-click menu for the social actions you use most.

## Features

- Whisper, Add WoW Friend and Invite, each on its own modifier key.
- Works on names in chat, the target and focus frames, the friends list, the Who list, the guild roster and Group Finder.
- Whisper on a name in chat opens a chat tab for that player and moves your whispers with them into it. Turn this off with Whisper in New Tab in the settings. Everywhere else Whisper opens the chat box ready to whisper.
- Battle.net friends get a Battle.net whisper, and Invite reaches the character they play.
- Add WoW Friend works on the target and focus frames, like Add WoW Friend in the game's own menu: the game asks you to confirm the request. The game doesn't let addons send friend requests by name, so it doesn't work on names in chat or lists.
- Inviting into a full party offers to convert it to a raid.
- Invite works like the game's own menu entry: it invites when you can, suggests the player to your leader when you are in a group without lead, and asks to join when you are alone and they are in a group. Turn off asking to join with Invite Asks to Join in the settings.

## Usage

1. Hold the key for an action and left-click a player name.
2. To change the keys, type `/ssc` or pick Social Shortcuts in the addon menu.
3. Pick a key for each action, or None to turn it off. Defaults restores the starting keys.

Commands: `/ssc`, `/ssc intro` and `/ssc help`.

Starting keys:

- macOS: Option whispers, Control adds a WoW Friend, Command invites.
- Windows: Ctrl whispers, Alt invites. Add WoW Friend starts on None, so give it a key if you want it.

The shortcuts are off in dungeons, raids and PvP matches, where the game hides player names.

In chat, the game opens a whisper on every left-click on a name, so an Invite click there also opens the whisper box. Press Esc to close it. Shift stays the game's own: Shift-click on a name inserts it or runs a /who.
