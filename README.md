# Social Shortcuts

Whisper, invite, ask to join or befriend a player with one modifier-click on their name.

- **Hold** a modifier key
- **Click** a player's name
- **Whisper, invite or befriend** them, no right-click menu

## Why use it

- **Skip the right-click menu** for the social actions you use most.
- **Works wherever names show.** Chat, target and focus frames, friends list, Who list, guild roster and Group Finder.
- **Invite does the right thing.** It invites, suggests the player to your leader, or asks to join, as the game's own menu does.

## Features

- Whisper, Add WoW Friend and Invite, each on its own key
- Whisper on a chat name opens a chat tab for that player and moves your whispers with them into it. Turn this off with Whisper in New Tab
- Everywhere else, Whisper opens the chat box ready to whisper
- Battle.net friends get a Battle.net whisper, and Invite reaches the character they play
- Inviting into a full party offers to convert it to a raid
- Turn off asking to join with Invite Asks to Join

## Quick start

1. Hold the key for an action and left-click a player name
2. Type `/ssc` or pick Social Shortcuts in the addon menu to change the keys
3. Pick a key for each action, or None to turn it off. Defaults restores the starting keys

## Starting keys

- **macOS:** Option whispers, Control adds a WoW Friend, Command invites
- **Windows:** Ctrl whispers, Alt invites. Add WoW Friend starts on None

## Commands

`/ssc`, `/ssc intro` and `/ssc help`

## Good to know

- Add WoW Friend works on the target and focus frames, and the game asks you to confirm. The game doesn't let addons send friend requests by name, so it doesn't work on names in chat or lists
- The shortcuts are off in dungeons, raids and PvP matches, where the game hides player names
- In chat, the game opens a whisper on every left-click on a name, so an Invite click there opens the whisper box too. Press Esc to close it
- Shift stays the game's own: Shift-click on a name inserts it or runs a /who
